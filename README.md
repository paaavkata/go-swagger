# go-swagger

Thin wrapper around `swaggo/swag` that configures a generated Swagger spec's host/base-path/schemes from environment variables (viper), consistently across backend services, and gates whether Swagger UI should be registered at all.

## Import

```go
import goswagger "github.com/paaavkata/go-swagger"
```

Package name: `goswagger`.

## API surface

- `Configure(spec *swag.Spec, appPort, defaultBasePath string)` — sets `spec.Host`, `spec.BasePath`, `spec.Schemes` based on `ENV`:
  - `dev`/`staging`: uses `HOST` + `SWAGGER_BASE_PATH` (falls back to `defaultBasePath`) — the gateway-facing address.
  - anything else (local/other): uses `127.0.0.1:<appPort or APP_PORT, default 8080>`, with base path only if `SWAGGER_BASE_PATH` is set.
  - Schemes come from `SWAGGER_SCHEMES` (comma-separated `http`/`https`) when set, otherwise `https` behind a base path and `http` locally.
- `Enabled() bool` — returns `false` when `ENV == "prod"`, `true` otherwise. Callers use this to decide whether to register the `/swagger` route at all.

## Usage

```go
spec := docs.SwaggerInfo // generated by swaggo/swag

if goswagger.Enabled() {
    goswagger.Configure(spec, os.Getenv("APP_PORT"), "/api/payment")
    e.GET("/swagger/*", echoSwagger.WrapHandler)
}
```
